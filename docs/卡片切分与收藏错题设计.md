# 卡片切分、收藏/错题集与 AI 索引设计

## 1. 原实现的问题

原卡片生成按“章”切分：

- 一个章节只生成 1 个 note；
- `front` 是章节标题，`back` 最多拼 6 个 block；
- 一张卡同时包含定义、分类、例子、注意事项；
- 结果是一张卡很胖、另一张卡很空，重点不稳定。

这不是 UI 问题，是切分粒度问题。

## 2. 新方案：原子知识点卡

### 2.1 切分单位

以“一句完整的话”为最小单位，而不是章或段落：

```text
章
→ block
→ 句子（。！？；）
→ 过滤导航/页眉/版权/过短句
→ 一条句子 = 一个候选知识点
```

不做“为了凑 300 字把下一句拼进来”的合并。

### 2.2 质量门槛

候选必须满足：

- 16～360 字；
- 不是页码、来源、目录、版权、扫码等噪声；
- 同一章内去重；
- 每章最多保留 8 个高价值候选。

价值评分是启发式，不是“真理”：

- 命中定义/分类/组成/原理/特点/作用/区别/步骤/公式等词；
- 含数字；
- 长度适中。

选完后仍按原文顺序排列，避免卡片顺序跳跃。

### 2.3 问题生成

优先用句式模板生成可回答的问题：

| 原文信号 | 生成的问题 |
|---|---|
| `是指` / `称为` / `是` | 什么是 X？ |
| `分为` | X 分为哪些部分？ |
| `组成` | X 由哪些部分组成？ |
| `包括` | X 包括哪些内容？ |
| `优点/缺点/作用/区别` | X 有哪些优点/缺点/作用/区别？ |
| 其他 | 请说明「章」中“X”的含义或要点。 |

没有用 LLM 生成问题，原因是：

- 批量教材导入不能依赖单次模型调用；
- 模型余额/超时会让整批失败；
- 模板问题可预测、可测试，用户仍可编辑。

### 2.4 导入协议

生成的 docx 中，每个原子知识点是一个 Heading 3：

```text
教材12｜第3章 传输层｜知识点 04

Q: TCP 三次握手的过程是什么？
A: 第一次客户端发送 SYN；第二次服务器回复 SYN+ACK；第三次客户端发送 ACK。
来源：教材翻译 计算机网络.pdf · 第3章 传输层
```

后端 `DocxImporter` 识别 `Q:` / `A:`，`ImportService` 只创建一张卡，不再走“核心结论 + 要点 + 易错”的整章拼盘。

旧 docx 没有 `Q:/A:` 时仍走旧逻辑，保持兼容。

## 3. 收藏与错题集

### 3.1 数据

不新增表，直接在 `card` 上加：

```sql
favorite      TINYINT NOT NULL DEFAULT 0
wrong         TINYINT NOT NULL DEFAULT 0
wrong_count   INT NOT NULL DEFAULT 0
last_wrong_at DATETIME(3)
```

- `favorite`：收藏；
- `wrong`：当前错题状态；
- `wrong_count`：历史做错次数；
- `last_wrong_at`：最近做错时间。

复习评分：

```text
rating 1/2 → wrong=1, wrong_count+1, last_wrong_at=now
rating 3/4 → wrong=0
```

### 3.2 接口

```http
POST /api/v1/cards/{id}/favorite?favorite=true
GET  /api/v1/cards?favorite=true
GET  /api/v1/cards?wrong=true
GET  /api/v1/collections/summary
GET  /api/v1/collections/favorites
GET  /api/v1/collections/wrong
GET  /api/v1/collections/ai-text
```

### 3.3 页面位置

```text
CARDS 卡片管理
  全部 / ★ 收藏 / 错题集

LIBRARY 资料
  └─ COLLECTIONS 收藏与错题
       ├─ 收藏列表
       ├─ 错题集列表
       └─ SYNC TO AI 索引
```

复习卡右侧增加“☆ 收藏本卡”，评分错误自动进入错题集。

## 4. AI 索引与 Embedding

`/api/v1/collections/ai-text` 输出 Markdown：

```markdown
# Memory Lab 收藏与错题集

## 收藏

### 问题
答案

## 错题集

### 问题
答案
```

前端 `SYNC TO AI 索引` 会：

1. 读取该 Markdown；
2. 查找/创建 Knowledge Base `Memory Lab 收藏与错题`；
3. 上传 `memorylab-collections.md`；
4. 调用 reindex。

DeepTutor 的 Embedding 配置生效后，集合会进入向量索引，导师可以用现有 RAG 检索。

注意：

- 没有配置 Embedding 时，文件仍会进入 Knowledge，但不会建向量索引；
- Embedding Key 与聊天 Key 不是同一个配置；
- 每次同步会生成一份新 Markdown，重建索引后以最新内容为准。

## 5. 迁移与兼容

- 迁移：`V4__collections.sql`；
- 旧卡片默认 `favorite=0, wrong=0`；
- 旧 docx 继续兼容；
- 新卡片来源标记 `原子知识点`。

## 6. 验收

```text
[ ] 一章导入后生成多张卡，每张只考一个点
[ ] Q/A 明确，front 不是“本章核心结论是什么”
[ ] 收藏后 CARDS 收藏筛选可见
[ ] 评分 1/2 后错题集可见
[ ] 评分 3/4 后从错题集移出，wrong_count 保留
[ ] ai-text 输出 Markdown
[ ] 配置 Embedding 后 Knowledge 重建索引成功
```
