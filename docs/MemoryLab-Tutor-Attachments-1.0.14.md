# 导师附件工作区（1.0.14）

## 入口

打开：

```text
AI 助手 → TUTOR 导师
```

在输入框上方现在有三样东西：

```text
+ ATTACH 附件     知识库下拉框     附件说明
```

## 上传后会怎样

1. 文件先在浏览器里读取为 base64。
2. 发送消息时，附件随同一条 DeepTutor WebSocket 请求进入当前对话，所以导师在**这一轮**就能读到文件内容。
3. 同时，文件会自动上传到你选择的知识库：
   - `Tutor 附件（自动索引）`：自动创建/使用名为 `Tutor 附件` 的 KB。
   - 已有知识库，例如 `操作系统`：附件直接进入该 KB。
4. 如果 Embedding 已配置，KB 会建立索引；如果没有配置，文件仍会归档，但暂时不能做向量检索。
5. 之后在同一个会话里继续提问，导师仍保留附件上下文；新会话里选择同一个 KB，也能通过检索读到它。

## 状态说明

附件 chip 上会显示：

```text
读取中…
待索引
上传知识库…
已送索引 · 知识库名
已归档 · 未配置Embedding
索引失败：...
```

`已送索引` 表示文件已经提交给 KB；索引完成时间取决于文档大小和机器性能。

## 产出文件

导师/工具生成的文件会作为 assistant 消息的附件显示：

- 有下载地址的：`OPEN`
- 未自动索引的：`INDEX 索引`

支持自动回传 KB 的扩展名：

```text
pdf doc docx ppt pptx md markdown txt epub
```

其他类型（例如图片、html）仍会显示，但不会自动送入 KB，避免把不支持的格式塞进检索库。

## 限制

- 单文件最大 20 MB
- 一次最多 5 个附件
- 附件上传和 KB 索引都需要本地 DeepTutor 服务（8001）正常
- 扫描版 PDF 仍受 OCR 质量影响
- 生成的文件如果只在模型回答里以文字出现、没有真实文件 URL/base64，就不会出现在附件区

## 隐私

附件会同时进入：

```text
当前对话的附件存储
你选择的知识库
```

如果资料敏感，先选择专用 KB，或不要勾选已有 KB；不要把自己的 `data` 目录连同 API Key 一起发给别人。

## 图片附件

导师页现在有两个入口：

```text
+ ATTACH 附件    PDF / Word / PPT / Markdown / TXT / EPUB
+ IMAGE 图片     PNG / JPG / JPEG / WEBP / GIF
```

也可以直接在聊天输入框里按 `Ctrl + V` 粘贴剪贴板图片。

图片的行为：

- 以 `type: image`、base64 发送给 DeepTutor，导师在当轮对话中可读取
- chip 上显示缩略图、文件名、大小和 `OPEN`
- 图片不会上传到文本知识库，状态显示 `仅对话 · 图片`
- 需要长期检索图片内容时，建议先 OCR/转成文字，再作为文档上传

图片仍然受 20 MB / 单次 5 个附件的限制。
