# 出题与判分

## 配比

一次学习 5 题：

| 题型 | 数量 | 考什么 |
|---|---|---|
| 回忆 | 2 | 这个概念、公式、结论是什么 |
| 应用 | 2 | 换个数字或场景还能不能用 |
| 反例 | 1 | 什么情况下不适用 |

从易到难排，不要一上来给最难的。

## 顺序

1. 先出全部题目
2. 等用户全部作答
3. 再给答案与解析

**不要边出题边给答案**，也不要"先讲一遍再考"——先答后看才是有效回忆。

用户明确说"直接给答案"时照做，但要在记录里标 `未作答`。

## 判分

每题给一个结论：`对` / `半对` / `错`。

- `半对` 必须指出缺了哪一步，不能只说"不完整"
- `错` 要说明是概念错、方法错还是计算错
- 蒙对但说不清理由的，按 `半对` 处理

## 记录

答错或半对的题写入 `记录.md` 的错题表：

`题 | 我的答案 | 错在哪一步 | 正确思路 | 复做日期`

复做日期按 `+1 天` / `+3 天` / `+7 天` 排。复做时换问法，不要重复原题。

## 状态更新

| 情况 | 状态 |
|---|---|
| 首次作答正确、且能说清理由 | `已掌握`（需连续两次才最终确认） |
| 答错、半对、或说不清理由 | `待复习` |
| 还没出过题 | `未测` |
