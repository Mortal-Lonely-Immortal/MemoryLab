# 配图规范

## 硬要求

每节至少一张**真正的图**：PNG 或 SVG 嵌入正文（docx 用 `add_picture`）。

**表格不算图，字符画（ASCII 树）也不算图。** 它们是两种不同的东西：表格适合逐项对比，图适合表达"关系"（流向、层级、状态变化）。用表格冒充配图，等于没画。

## 先选图式，再动手画

| 要表达的关系 | 用什么 |
|---|---|
| 组成、层级 | 结构图（树形、分层块） |
| 步骤、判断 | 流程图 |
| 两个概念对比 | 表格，不要硬画成图 |
| 时间上的先后 | 时序图 |
| 状态与转移 | 状态图 |

不要把什么都画成放射状思维导图——那是目录，不是解释。

## 工具

- 默认 Mermaid：文本可编辑、渲染稳定、不用处理字体
- 需要精细控制版面时用 SVG
- 机器上没有 graphviz / mermaid / matplotlib 时，用 Pillow 直接画：圆角矩形 + 箭头 + `msyh.ttc` 中文字体，
  白底、深灰线条、最多三种颜色，1000px 宽足够
- 不要用截图代替自己画的图，除非原图本身就是证据（例如 slide 上的实验数据）
- 中文图注意字体：SVG 里显式指定常见中文字体，别依赖默认字体

## 验收

三个问题，全过才算合格：

1. 遮住正文，只看图能说出 3 个要点吗？
2. 图里有正文没提到的信息吗？有的话，要么删掉，要么补进正文
3. 箭头方向和文字标签有歧义吗？

## 反例

- 把整段文字塞进方框
- 一张图超过 10 个节点
- 用颜色区分含义却不给图例
- 图和正文各说各话，图只是装饰
