# 讲义格式

## 讲义.docx（给人读）

章节顺序固定：

1. **标题页**：主题、日期、覆盖范围（章节 / 页码 / slide 编号）
2. **术语表**：术语 | 一句话解释 | 例子
3. **正文**：按知识块分节，每节写四件事
   - 一句直觉说法
   - 再给准确表述
   - 一个例子
   - 一个反例（什么情况下不成立）
4. **配图**：每节最多一张，图下写一句"这张图在说什么"
5. **练习**：题目集中放，答案统一放最后，不插在题后
6. **复习要点**：5 条以内

排版要求：

- 标题层级只用两级（标题 + 小节），不要四级套娃
- 段落不超过 4 行
- 中英文、数字之间留空格
- 公式用 `$...$` 或独立公式块，不要用图片代替

## 讲义.md（给模型读）

只保留五类，其余全删：

| 保留 | 示例 |
|---|---|
| 术语表 | `幂等：重复执行结果一致` |
| 结论 | `接口要幂等，因为重试与查询之间存在竞态` |
| 公式 | `T(n) = 2T(n/2) + O(n)` |
| 易错点 | `别用"先查再写"防重复` |
| 题目与答案 | `Q: … / A: …` |

目标长度：docx 版的三分之一以内。不写过渡句，不写"接下来我们看"。

## PPT 的特殊处理

PPT 是提纲，不是讲义。按这个顺序还原：

1. 先列出全部 slide 标题，标出哪些是承接、哪些是跳跃
2. 跳跃处补推理，并标 `[推断]`
3. 每页只留一个结论；一页出现多个结论时拆成几节
4. 图比字重要：先描述 slide 上的图，再解释它想说明什么
5. 补充页（"谢谢""Q&A""谢谢观看"）直接跳过

不要写"第 3 页讲了……"这种页码索引，用户要的是知识结构，不是翻页指南。

## 记录.md

```markdown
# <主题> 学习记录

## 覆盖范围

- 已学：
- 未学：

## 知识点状态

| 知识点 | 状态 | 最近一次作答 | 备注 |
|---|---|---|---|
| | 未测 | | |

## 错题

| 题 | 我的答案 | 错在哪一步 | 正确思路 | 复做日期 |
|---|---|---|---|---|
| | | | | |

## 下次

1.
```

状态只有三个值：`未测` / `待复习` / `已掌握`。没出过题的一律 `未测`。
