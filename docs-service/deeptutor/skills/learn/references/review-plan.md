# 长期复习

单次学习结束后，用这份规则把知识点排进复习队列。

## 节奏

| 轮次 | 时间 | 做什么 |
|---|---|---|
| R1 | 当天 | 一页纸复述，不看材料 |
| R2 | +1 天 | 只过错题 |
| R3 | +3 天 | 错题 + 随机抽 30% 已掌握的点 |
| R4 | +7 天 | 用一页纸重构整章结构 |
| R5 | +15 天 | 2 道应用题 |
| R6 | +30 天 | 讲给外行听（费曼式复述） |

答错 → 该点回到 +1 天；连续两次独立答对 → 进入下一轮。

`已掌握` 超过 30 天没复做 → 降为 `待复习`。

## 每次复习只做两件事

先合上材料回忆，再对照答案。不重讲、不重读讲义、不补新内容。

## 复习题的来源

1. 优先错题本里 `待复习` 的条目
2. 其次随机抽 `已掌握` 的点，换问法，不重复原题
3. 不做没学过的内容

## 什么时候移出队列

一个知识点连续两次独立答对，且两次间隔 ≥7 天，可以移出队列，标 `已掌握`，并附两次作答记录。

## 和 `记录.md` 的关系

`记录.md` 的「复做日期」列就是这份队列的落地。每次复习后更新那一列，不要另建文件。

## 不要做的事

- 不要把复习做成"再讲一遍"——那就退化成重读，没有检索效果
- 不要为了清空队列而降低题目难度
- 不要一次复习超过 20 分钟；超过说明当天的量排多了，下次减半
