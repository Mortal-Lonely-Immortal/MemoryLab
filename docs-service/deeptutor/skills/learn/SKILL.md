# 学懂一段材料

先定靶子 → 定范围 → 讲明白 → 配图 → 一页纸复述 → 出题验证 → 记下状态 → 排复习 → 排下次内容。

全程只有一个核心动作：**一页纸复述**。合上材料，用一页纸画出结构或写出要点；做不出来，就是没学会。

## 不变量

- 先读原文再讲解；原文没覆盖的内容标 `未覆盖`，不补编。
- 讲解与原文分开标注：`[原文]` / `[解释]` / `[推断]`。
- 没有实际作答，不得标记 `已掌握`。
- 一次只推进一个主题，用户没要求时不整篇铺开。
- 专业名词与英文术语**首次出现时内联** `（中文解释）`，例如 `CAS（比较并交换）`；术语表只是索引，不能替代内联。

## 第 0 步：定靶子

讲之前必须知道"为什么要学这些"，否则每一节都只是碎片。

1. 问清三件事：**目标**（岗位与公司类型）、**经验**、**离 deadline 的时间**。问不到就不定范围。
2. 把材料做三级分类：**必背 / 懂概念 / 不看**，砍完再讲。同一节在不同靶子下分级不同。
3. 选一条**主线**（默认「一次请求的生命周期」），让每一节回答"我在主线的哪一环"。
4. 产出 `知识地图.md`，再开始讲。

规则、三条主线、地图模板见 `references/mission.md`。

## 流程

每步三行：做什么 / 判据 / 没过怎么办。判据要能数出来，不能靠感觉。

1. **定范围** — 列出覆盖的章节、页码、slide 或文件。
   判据：清单 ≥3 项；明确写出 ≥1 项"本次不学"**及其理由**；分级表（必背/懂概念/不看）已产出。
   没过：还没靶子 → 回第 0 步；材料缺口 → 列出缺什么，停下问用户。

2. **建术语表** — 每个术语给"一句话解释 + 一个例子"。
   判据：术语 ≥5 个（材料不足时按实际），无空单元格，解释里不出现未定义术语。
   没过：解释不出来的 → 回第 1 步补材料，或标 `未覆盖`。

3. **通俗讲解** — 先用日常语言讲一遍，再补准确表述。
   判据：每个结论都带 `[原文]` 或 `[推断]`；未在术语表出现的专业词 = 0 个。
   没过：出现未定义词 → 回第 2 步补术语表，不硬讲。

4. **配图** — 每节至少一张图，按材料类型选图式，规则见 `references/figure-spec.md`。
   判据：图已嵌入正文（PNG/SVG）；单图 ≤10 节点；遮住正文能看图说出 ≥3 个要点；图信息 ⊆ 正文信息。
   没过：画不出图 → 改用表格并注明"本节无图"；**不许用字符画或纯表格冒充配图**。

5. **一页纸复述** — 让用户合上材料自己写。
   判据：用户写出 ≥3 个要点，或明确指出 ≥1 个断点。
   没过：写不出来 → 回第 3 步换讲法（换类比、换例子），不进第 6 步。

6. **出题检验** — 5 题（2 回忆 / 2 应用 / 1 反例），先答后看，规则见 `references/quiz-rules.md`。
   判据：用户全部作答前不给答案；每题给 `对 / 半对 / 错` + 一句原因。
   没过：某题全错 → 该知识点记 `待复习`，并在第 7 步单独列出。

7. **记录状态** — 每个知识点标 `未测 / 待复习 / 已掌握`，写入 `记录.md`。
   判据：每条都有状态；标 `已掌握` 的必须附最近一次作答原文。
   没过：缺作答证据 → 一律降为 `未测`。

8. **排复习** — 按 `references/review-plan.md` 的节奏给每个知识点排复做日期。
   判据：`记录.md` 的「复做日期」列无空值；最晚一条不超过 +30 天。
   没过：写不出日期的知识点 → 说明它还没进队列，标 `未测`。

9. **排下次** — 3 条待办，每条指向具体材料位置。
   判据：每条含"材料位置 + 动作 + 预计用时"，三项齐才算合格。
   没过：写不出具体位置 → 删掉这条，改写成"需用户补充 X"。

## 三种材料，三个入口

- **课本 / 讲义**（知识为主）：流程全走，重点在术语表和例题。
- **老师 PPT**（提炼为主）：先还原逻辑链，再补跳跃处的推理。
- **项目源码**（理解为主）：先给模块图，再沿一条主调用链讲。

三种材料的具体做法、检查表和常见坑：`references/modes.md`。

## 复习

学完不等于记住。复习按 `references/review-plan.md` 的节奏走，落点在 `记录.md` 的「复做日期」列。

复习时只做两件事：先合上材料回忆，再对照答案。不重讲、不重读讲义——那只是重读，没有检索效果。

## 产物

```text
学习-<主题>/
├── 知识地图.md   主线、章节挂载、分级表（第 0 步产出）
├── 讲义.docx     给人读
├── 讲义.md       给模型读（压缩版）
├── 记录.md       掌握状态、错题、复做日期、下次计划
└── 素材/         图、摘录、原始截图
```

同一主题再次学习时更新原文件，不新建文件夹。

`讲义.docx` 用 `office-docx` 生成；`讲义.md` 只保留术语表、结论、公式、易错点、题目与答案，长度压到 docx 的三分之一以内。

## 收尾

每次结束给两句话：**现在能做什么**、**下次从哪继续**。

如果这次没做出一页纸复述，就不算完成，直接说"还差这一步"，不要用鼓励性措辞掩盖。
